# **r⁵py** example cases

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/r5py/case-studies/HEAD)
[![nbviewer](https://raw.githubusercontent.com/jupyter/design/refs/heads/main/logos/Badges/nbviewer_badge.svg)](https://nbviewer.org/github/r5py/case-studies/)

This repository contains example cases that demonstrate the use of r⁵py. It is
supplementary material to a manuscript that has been submitted to a journal and
is currently under review.


## Run on your local computer

To reproduce the examples (which only use openly available online sources) on
your local computer, check out this repository, install dependencies as listed
in `requirements.txt` and start jupyter lab:

```
git clone https://github.com/r5py/case-studies.git r5py-case-studies
cd r5py-case-studies
python -m venv .virtualenv
source .virtualenv/bin/activate
pip install -r requirements.txt
jupyter lab
```
